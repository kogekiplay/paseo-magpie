# Release checklist

Before each release, check whether the change affects the manifest description, the README, the English and Chinese overviews, or the screenshots listed in `paseo-plugin.json`. Update the affected material in the release. Use current UI and sample data when recapturing previews.

The Paseo registry pins a Git commit. When updating the official listing, submit the released commit so that its description, overview, and previews come from the same version.
